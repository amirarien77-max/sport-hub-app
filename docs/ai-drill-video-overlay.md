# שרטוט AI על וידאו תרגיל (Drill Overlay)

מצלמים תרגיל, מעלים אותו לתרגיל בלוח הטקטי, וה־AI מצייר מסלולים וחצים **לאורך כל הסרטון** — לא רק על פריים אחד.

## איך משתמשים באפליקציה

1. היכנסו ללשונית **לוח טקטי** ופתחו תרגיל (או צרו חדש).
2. במקטע **שרטוט AI על וידאו**:
   - **צילום תרגיל** — מצלמים וידאו במכשיר (מאמן).
   - **בחירת וידאו מהגלריה** — מעלים קובץ קיים.
3. לחצו **הפעלת שרטוט AI**.
4. הנגן מציג את הווידאו עם שכבת SVG מסונכרנת לזמן הניגון (מסלולי חיתוך, חצי מסירה, סימוני עמדה).

במצב דמו (בלי העלאה חיה) אפשר עדיין להפעיל שרטוט — יופיע **דמו** על מגרש ירוק עם שעון פנימי.

## איך זה עובד טכנית

| שלב | מה קורה |
|-----|---------|
| העלאה | אותו דלי `tactical-media` כמו מדיה רגילה (`{teamId}/{playId}/…`) → `media_url` |
| ניתוח | Edge Function `drill-overlay` (או stub מקומי) מחזיר `keyframes` מתוזמנים |
| תצוגה | `DrillOverlayPlayer` מצייר SVG מעל `expo-video` ומדגים לפי `currentTime` |

אין קידוד וידאו מחדש בשרת בגרסה הראשונה — השרטוט הוא שכבה חיה על הנגן.

### מבנה ה־JSON (cache)

נשמר ב־`tactical_plays.drill_overlay_json` (מיגרציה `019_drill_overlay.sql`):

- `mode`: `openai` | `offline_stub`
- `summary`: טקסט עברי קצר
- `durationSec`: משך השרטוט
- `keyframes[]`: `{ t, paths, arrows, markers, courtGuide }` עם קואורדינטות 0–100

## הגדרת OpenAI (אופציונלי)

אותו סוד כמו Game IQ:

1. Deploy: `supabase functions deploy drill-overlay`
2. Dashboard → Project → Edge Functions → Secrets → הוסיפו `OPENAI_API_KEY`
3. הריצו את המיגרציה `019_drill_overlay.sql` ב־SQL Editor

**בלי מפתח / בלי פונקציה / שגיאת רשת:** האפליקציה לא נחסמת — מוצג מצב אופליין בעברית עם שרטוט דמו מלא לאורך הזמן.

לעולם אל תשימו מפתח OpenAI ב־`EXPO_PUBLIC_*`.

## הרשאות

- צילום/העלאה: מאמן (צוות) במצב חי.
- הפעלת שרטוט וצפייה: מאמן ושחקן (כולל דמו).
